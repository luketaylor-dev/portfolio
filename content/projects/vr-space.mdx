# VR Space Station Climber

A short **VR prototype** created to explore immersive climbing mechanics in a zero-gravity environment. Using free NASA assets, this project focused on physics-based traversal and testing different VR frameworks.

## Overview

Built in just one week, the VR Space Station Climber experimented with how climbing and traversal could feel in a zero-G setting, comparing different SDK approaches.

## Technical Implementation

- Unity + C#
- Meta SDK and Unity XR Interaction Toolkit for core climbing
- UltimateXR package to test a preconfigured VR system
- Physics-based interactions for realistic grip and momentum

## Why It Matters

This project provided insights into the trade-offs between **custom flexibility** and **preconfigured VR frameworks**, helping to guide future decisions in VR gameplay design.

## Future Potential

- Expansion into a full VR traversal demo with multiple space environments
- Cooperative multiplayer climbing challenges
- Comfort refinements (motion sickness and fatigue mitigation)
