# Free-to-Play Poker Suite

Developed and shipped a suite of **free-to-play poker and casino apps** built in **Unity** for iOS and Android.  
These titles were designed to support large-scale player bases through a combination of LiveOps pipelines, monetisation strategies, and scalable Unity engineering.

## Overview

The Poker Suite exemplifies how free-to-play game economy design can be combined with robust technical systems to deliver engaging, revenue-generating mobile titles.  
From segmented in-app purchases to cross-promotion features, the projects balanced **player engagement**, **business goals**, and **engineering scalability**.

## Key Features

- **Segmented IAP Flows** – personalised offers based on user segments, optimising ARPU
- **Seasonal Pipelines** – rotating events, challenges, and asset swaps for ongoing player engagement
- **Cross-Promotion Systems** – integrated features connecting multiple titles to strengthen retention
- **Analytics & A/B Testing** – data-driven iteration on monetisation, engagement, and UX flows

## Technical Implementation

- Built with **Unity (C#)** targeting iOS and Android
- **Firebase Remote Config** for remote balancing and feature toggles
- **Unity Addressables** for live asset streaming and seasonal content swaps
- **Custom build tools** for rapid seasonal updates and reduced release overhead
- Integrated **Firebase Analytics** for player behaviour insights
- Applied **Unity Cloud Build** for continuous integration and multi-title support

## Impact

- Sustained **multi-million dollar annual revenue** across the portfolio
- Achieved **99.8% crash-free sessions**, ensuring reliable large-scale deployment
- Reduced time-to-market by **15%** with streamlined pipelines
- Increased ARPU by **20%** through segmented IAP design
- Boosted retention and installs during campaigns with cross-promotion features

## Future Potential

- Expansion into new card and casino variants using the same framework
- Enhanced social features (clans, tournaments, real-time multiplayer)
- Deeper personalisation with machine learning–driven segmentation
- Further automation of seasonal content pipelines
