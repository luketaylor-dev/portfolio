# Tatfindr

As **founding developer** on Tatfindr, I built the core platform that helps customers find tattoo artists by location and style, view portfolios, and send structured enquiries.

## Overview

Tatfindr is a full-stack web application with a **Next.js** frontend and **ASP.NET Core** backend. The frontend uses Tailwind CSS, shadcn/ui, and Flowbite Premium for a polished UI. The API handles authentication (ASP.NET Identity + JWT), search, bookings, and email via Resend.

## Tech Stack

- **Frontend:** Next.js 16, React, TypeScript, Tailwind, shadcn/ui
- **Backend:** ASP.NET Core 8, EF Core 8, PostgreSQL
- **Auth:** ASP.NET Identity, JWT
- **Email:** Resend
- **DevOps:** Docker, Docker Compose for local dev

## Role

As founding developer, I designed and implemented the architecture, core API, database schema, and frontend structure. The platform is built for scale, with proper validation, logging, and observability (Serilog, OpenTelemetry) from the ground up.

## Why It Matters

Tatfindr demonstrates that I can lead full-stack web projects from concept to production. The same engineering discipline, clear architecture, testable code, and maintainable systems, applies whether the product is a game, a VR experience, or a web marketplace.
