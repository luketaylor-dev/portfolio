# Portfolio Site

This portfolio site is a hands-on demonstration of modern web development. Built with **Next.js 16**, **React**, and **TypeScript**, it showcases full-stack patterns, MDX-driven content, and a cohesive design system.

## Overview

The site uses the App Router for server-side rendering and static generation, with edge runtime for dynamic OG image generation. Content for blog posts and projects is loaded via **gray-matter** and **next-mdx-remote**, with no separate content build step.

## Technical Highlights

- **Next.js 16** – App Router, Server Components, Turbopack
- **TypeScript** – Strict typing across the codebase
- **Tailwind CSS** – Custom primary palette, responsive layout
- **MDX** – Blog and project content with syntax highlighting
- **OG Images** – Dynamic Open Graph images with custom fonts

## Why It Matters

Beyond showcasing Unity work, this site proves I can ship production-quality web applications. The same attention to structure, performance, and maintainability applies to both game dev and web projects.
